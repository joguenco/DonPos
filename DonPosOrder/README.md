# DonPosOrder
DonPos Order

## Software
* Java 25
* Micronaut (View on gradle.properties file)
* MariaDB
* Gradle 9.6.0

## Format
```
gradle spotlessApply
```

## Date Format
```
@JsonFormat(pattern = "yyyy-MM-dd'T'HH:mm")
```

### Run
```
gradle run
```
### Run Hot Reload
```
gradle run --continuous
```
### Task
```
gradle task
```
### Compile
```
gradle assemble
```
or
```
gradle build
```
